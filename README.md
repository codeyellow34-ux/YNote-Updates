# Y-Note 업데이트 공지

이 저장소는 Y-Note가 읽는 공개 업데이트 공지만 관리합니다.

## 허용 파일

- `latest.json`: 공지 활성 여부, 버전, 공지 식별자, 패치 내용
- `README.md`: 공지 관리 안내
- `.gitignore`: 공지 파일 외의 일반적인 Git 추가를 방지하는 설정

프로그램 소스, 설치파일, 사용자 메모·백업, 개인정보, 인증정보, 로그는 올리지 않습니다. 개발 저장소와 별도로 관리하며 폴더 전체 업로드나 일괄 추가를 사용하지 않습니다.

`.gitignore`는 실수 방지용이며 GitHub 웹 업로드나 강제 추가를 차단하지는 않습니다. 게시할 때마다 허용된 파일 목록과 파일 내용, 변경 기록의 작성자 정보를 확인합니다. 변경 기록은 GitHub의 비공개용 이메일을 사용합니다.

## 공지 관리

`latest.json`만 수정합니다. `active`가 `true`이고 공지 버전이 설치된 버전보다 높을 때 업데이트 안내 대상이 됩니다. 새 패치는 더 높은 4자리 버전과 새로운 `releaseId`를 사용합니다. 공지를 내릴 때는 `active`를 `false`로 바꿉니다.

형식은 `schema`, `active`, `releaseId`, `version`, `patchNotes`만 사용합니다. 파일은 UTF-8 64 KiB 이하, 공지 식별자는 영문·숫자·하이픈·밑줄·마침표 80자 이하, 버전은 숫자 4자리 구분 형식, 패치 내용은 최대 20개·각 500자·합계 8,000자 이하로 작성합니다. 안내에는 개인 정보나 비공개 작업 내용을 넣지 않습니다.

업데이트 이동 주소는 프로그램에 고정된 배포 안내 페이지를 사용합니다. 이 저장소에는 다운로드 주소나 인증 토큰을 추가하지 않습니다.

현재 공지는 표시 동작을 확인하는 테스트입니다. 실제 새 설치파일이 배포된 것은 아닙니다.
